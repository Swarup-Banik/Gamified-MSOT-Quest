# MSOT Quest — Voice & Microcopy Style Guide

This guide establishes the tone, terminology, error handling philosophy, and microcopy standards for MSOT Quest.

---

## 1. Tone Pillars

1. **Friendly, Energizing & Peer-Like**: We talk to students like an encouraging co-op gaming partner, not a stern academic administrator.
2. **Short & Punchy**: Keep text scannable. Never write a paragraph when a punchy phrase or bullet list will do.
3. **Zero Shame, Zero Panic**: Wrong answers, streak lapses, and system errors are framed as learning stepping stones or quiet recovery opportunities, never failures.
4. **Actionable Over Explanatory**: Tell the user what happened and what they can do next in 1–2 sentences.

---

## 2. Official Game Vocabulary (Used Consistently)

| Forbidden Word | Preferred Game Term | Rationale |
|---|---|---|
| Daily Quiz / Test | **Today's Run** | Feels like a daily quest in a rogue-like game. |
| Homework / Assignment | **Topic Quest / Bounty** | Reframes academic work as an adventure milestone. |
| Mistake / Wrong Answer | **Mistake Monster** | Externalizes errors so students fight them, rather than feeling defective. |
| Loot Box / Reward Box | **Mystery Vault / Chest** | Playful, treasure-chest imagery without predatory connotations. |
| In-game Currency | **Spendable Shards** | Crafting resource earned strictly via academic effort. |
| Exam / Midterm | **Boss Encounter / Raid** | High-stakes summative review treated as a cooperative raid. |
| Review / Remediation | **Revenge Arena** | Empowering re-challenge mechanic to banish recurring misconceptions. |

## 3. Microcopy by Scenario

### 3.1 Quiz Feedback
- **Correct Answer**:
  - *"Bullseye! +15 XP"*
  - *"Spot on! Concept mastered."*
  - *"Flawless logic!"*
- **Incorrect Answer (Gentle Nudge)**:
  - *"Almost! Notice how the pointer behaves when the list is empty."*
  - *"A mischievous Off-by-One Imp appeared! You can banish it in the Arena."*
  - *"Tricky edge case! Let's review why option B holds."*

### 3.2 Streaks & Freeze Shields
- **Active Streak**: *"4-day streak alive! Consistency is king."*
- **Preserved by Freeze**: *"Streak Shield activated! You missed yesterday, but your 7-day flame was kept safe. Zero guilt."*
- **Streak Lapsed**: *"A fresh run begins today! Every master starts at Day 1."*

### 3.3 Integrations & Verification (LeetCode, HackerRank, GitHub)
- **Daily Cap Hit**: *"You've hit today's verified coding XP cap (70 XP). More solves still earn badge progress and campus league rank!"*
- **Provider Down / Rate-Limited**: *"LeetCode is catching its breath. We'll automatically catch up on your solves as soon as it recovers."*
- **Verification Success**: *"Ownership verified! @handle is now synced. +50 Bonus XP!"*

### 3.4 Errors & Empty States
- **Network Disconnect**: *"Disconnected from Campus Realm. Reconnecting automatically..."*
- **Empty Inventory / Codex**: *"Your Codex shelf is quiet right now. Crack open a Mystery Chest from Today's Run to discover your first companion aura!"*
- **404 Not Found**: *"You strayed off the campus map! Even legendary explorers take a wrong turn. Let's head back to the Lobby."*

---

## 4. Accessibility & Inclusive Language
- Always accompany rarity colors with distinct icon shapes or text tags (e.g. `[Rare]`, `[Epic]`).
- Do not use flashing, alarmist text or high-pitched warning buzzers.
- All icon-only buttons require an explicit `aria-label` or `title` matching our vocabulary.
